**Also called:** *Arnold Alarm*

## What it means

The whole campus safety platform: phone app, desk console, fobs, campus horns, and Alert Line (9090). Staff use it to ring class bells and declare Code Red or Code Blue.

## How to use this term

Say **Arnold Alert** when you mean the tool at alarm.arnoldcoc.org — not this playbook site.

## Not the same as

- Arnold Emergency (this website — the human SOP)
