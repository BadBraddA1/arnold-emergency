## What it means

IVR menu on UniFi Talk: page, test, PIN codes, fob arm, system arm. Caller ID may show **Campus Security**.

## How to use this term

**Not** the primary way to declare a code in a crisis — use Alert Mobile or an armed fob. OK for paging (press 1) when appropriate.
