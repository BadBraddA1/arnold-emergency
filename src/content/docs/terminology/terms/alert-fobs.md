title: Alert Fobs
description: Physical emergency buttons

## What it means

Carried devices: button **1** = Code Red, **2** = Code Blue, **4** = All clear. Registered in Alert Desk → System → Fobs.

## How to use this term

Must **Fob Arm** before buttons work. Activity log shows who had it armed.
