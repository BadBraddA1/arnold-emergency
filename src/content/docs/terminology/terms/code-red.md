title: Code Red
description: Evacuate
---


## What it means

Campus emergency code meaning **leave the building** and go to the assembly area. Red tone loops on campus horns until all clear.

## How to use this term

Fire, smoke, gas, structural hazard, or when the incident commander orders evacuation.
