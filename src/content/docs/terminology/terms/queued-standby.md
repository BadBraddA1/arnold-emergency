---
title: Queued (standby)
description: Command recorded while standby
---


**Also called:** *Held*

## What it means

Someone triggered a bell or code while the system was on standby. Logged in Desk Activity; horns did not play.

## How to use this term

Admin arms the system if the command should still run (usually review first).
