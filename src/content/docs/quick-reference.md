```
CODE RED  = EVACUATE     → leave building → assembly: _______________
CODE BLUE = LOCKDOWN     → secure room, lights off, quiet
ALL CLEAR = IC only      → Stop & All clear in app / fob button 4

911 first when life is at risk.
Do NOT use phone PA (9090) for codes.
Medical emergency? Call 911 — see emergency.arnoldcoc.org/medical-emergency/
```

## At a glance

| Code | Meaning | You should |
|------|---------|------------|
| **Code Red** | Evacuate | Leave the building; go to assembly area |
| **Code Blue** | Lockdown | Secure room; lights off; phones silent |
| **All clear** | Emergency over | Resume normal — **only when leadership says so** |
