description: Printable emergency card for Arnold Church of Christ staff.
---

```
CODE RED — EVACUATE
Leave building now. Assembly: South parking lot
Take roster. Count heads. Report missing to IC.

CODE BLUE — LOCKDOWN
Lock room. Lights off. Phones silent. Stay put, stay quiet.
Do not leave. Do not open door except police or verified IC.

ALL CLEAR — WAIT FOR IC
Code Green (2 tones) or official word from leadership.
Only IC ends the code (app or fob 4). Room staff: do not press all clear.

911 first when life is at risk.
Do NOT use phone PA (9090) for codes.
Medical emergency? Call 911 — heart attack, stroke, bleeding, CPR:
emergency.arnoldcoc.org/medical-emergency/
```

## At a glance

| Code | Meaning | You should |
|------|---------|------------|
| **Code Red** | Evacuate | Leave now; take roster; go to assembly area |
| **Code Blue** | Lockdown | Lock room; lights off; phones silent; shelter in place |
| **All clear** | Emergency over | Wait for Code Green or IC — **room staff do not end the code** |

## Assembly area

**Primary assembly:** South parking lot

**Secondary (severe weather):** Lower auditorium (Level 1) — only if IC directs; otherwise remain in south lot away from building. Do **not** use fellowship hall (Level 2) as weather shelter.
