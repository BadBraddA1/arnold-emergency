title: Post-incident
description: Debrief and follow-up after an emergency at Arnold Church of Christ.
---

Within **72 hours** of any Code Red or Code Blue (including drills that surface gaps):

## Debrief

1. Short meeting: timeline, what worked, what did not.
2. Review **Desk Activity** in [Alert Desk](https://alarm.arnoldcoc.org/desk/) — who triggered what, when.
3. Update this site if roles, assembly points, or room handouts changed.
4. File insurance / incident reports per church policy.

## Questions to ask

- Was the correct code (Red vs. Blue) used first?
- Was 911 called at the right time?
- Were nursery and classrooms accounted for?
- Did anyone call all clear without IC approval?
- Do classroom handouts need updates?
- Did media or social media follow the [communication playbook](/communication/#media-and-social-media-playbook)? Any corrections needed?

## Update this site after debrief

If roles, assembly points, or room handouts need changes, contact **Adin Bradd** (System Admin) or an elder so the playbook stays current.
