For **classroom teachers**, adult Bible class leads, and anyone responsible for a roster in a room. Complete [Everyone](/orientation/everyone/) first. Nursery workers: also read [Nursery & children](/orientation/nursery/).

## Your job in one line

Protect the people in **your room** — evacuate or lock down correctly, take the roster, and wait for IC before you stand down.

## Day-one checklist

- [ ] Finish [Everyone](/orientation/everyone/)
- [ ] Find **your room** on [Rooms](/rooms/) — exit path, assembly, map
- [ ] Check in with your Alert PIN on that room page
- [ ] Confirm a printed [door card](/classroom/door-cards/) is by the door (or print one)
- [ ] Know where the roster / attendance sheet lives every week
- [ ] Listen to [Campus audio](/system/campus-audio/) so you recognize Red vs Blue by ear
- [ ] Know who your hallway / area lead is if one is assigned

## Code Red — Evacuate

1. Stop class calmly: *“We’re leaving — follow me.”*
2. Take **roster**. Line up. Nearest **safe** exit (use ADA exits for wheelchairs — see your map).
3. Go to **south parking lot**. Count heads. Report missing to IC immediately.
4. Do not re-enter for bags or phones.
5. Reunify children only with authorized guardians (children’s classes — see nursery guide).

Full steps: [Code Red](/codes/code-red/).

## Code Blue — Lockdown

1. Lock the door. Lights off. Phones **silent**.
2. Move away from door / windows as your room allows. Stay quiet.
3. Do **not** open for unknown voices — only police or verified IC.
4. Do not leave to “check the hallway.”
5. Wait for Code Green / IC — **you do not end the code**.

Full steps: [Code Blue](/codes/code-blue/).

## Pulpit / large group teaching

If you are leading worship or a combined class when horns sound:

- Stop the gathering.
- Give one clear direction matching the code (evacuate **or** lockdown — not both).
- Do not contradict IC if the code type changes.
- Details: [Roles — Worship / teaching](/roles/#worship--teaching-lead-pulpit)

## After all clear

- Return only when directed.
- Note anything confusing (wrong exit, missing roster) for [post-incident](/post-incident/) or your ministry lead.
