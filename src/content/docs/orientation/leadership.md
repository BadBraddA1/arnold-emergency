## Your job in one line

Decide **Red vs Blue**, make sure **911** is called, account for **children**, authorize **all clear**, and keep **one public voice**.

## Decision snapshot

| Situation | Usual code |
|-----------|------------|
| Fire, smoke, gas, structural hazard | **Code Red** |
| Threat inside / violence / unknown intruder | **Code Blue** |
| Single medical event in one room | Often **no** horns — 911 + local response |
| End of event | **All clear** only when you (or backup) authorize |

Horns **announce**; they do not think. See [System limits](/system/limits/).

## First five minutes (you are IC)

1. Confirm code type matches reality (change it if needed).
2. Confirm **911** in progress when required.
3. Assign: nursery/children accountability · someone at main entrance for first responders · spokesperson if media likely.
4. Hold **all clear** until threat is resolved and you are ready.
5. Afterward: schedule [post-incident](/post-incident/) within 72 hours.

## Communication

- You approve facts; spokesperson speaks publicly.
- No speculation on numbers, names, or motives.
- Full playbook: [Communication](/communication/).
