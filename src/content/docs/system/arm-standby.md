---
title: Arm & standby
description: System armed vs standby — not the same as emergency codes.
---

Separate from Code Red / Blue:

| State | Arnold Alert name | Meaning |
|-------|-------------------|---------|
| **Armed** | **System Armed** | Horns will play bells and codes (normal default) |
| **Unarmed** | **System Standby** | Commands logged but **held** — horns stay silent |

## Who may arm / disarm

**System Admin** PIN holders:

- Alert Control (mobile Admin panel)
- Alert Desk → System
- 9090 → press **5** → admin PIN

## When to use standby

- Maintenance or AV work in empty building
- Preventing accidental horns during testing
- **Do not** leave standby during public gatherings without explicit reason

## Held commands

While standby, staff can still tap codes — they appear in the activity log as **Queued (standby)** until an admin arms again.
