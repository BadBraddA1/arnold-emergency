**Arnold Alert** is the campus safety system (bells, emergency codes, PA, fobs).  
**Arnold Emergency** (this site) is the human playbook.

| Tool | URL | Who |
|------|-----|-----|
| **Alert Mobile** | [alarm.arnoldcoc.org](https://alarm.arnoldcoc.org) | All staff — codes, bells, fob arm |
| **Alert Desk** | [alarm.arnoldcoc.org/desk/](https://alarm.arnoldcoc.org/desk/) | System admins |

**Staff sentence:** *"Open Arnold Alert on your phone; admins use Alert Desk on a computer."*

## What happens when you trigger a code

1. Staff triggers Code Red or Blue (app, fob, or 9090 menu).
2. Phone shows **Alert Countdown** (10 seconds) — campus is silent until Send.
3. **Campus Horns** play the code tone and loop until **All clear**.
4. Activity is logged in **Desk Activity**.

## Alert Fobs

Physical buttons on a carried fob:

| Button | Action |
|--------|--------|
| **1** | Code Red |
| **2** | Code Blue |
| **4** | All clear |

Must **arm** fob first (3 hours) — app or 9090 → 4 → PIN.

## Alert Line (9090)

| Press | Function |
|-------|----------|
| **1** | Alert Page — convenience PA only |
| **2** | Line test — earpiece only, horns silent |
| **3** | Alert Line Codes — PIN emergency |
| **4** | Fob Arm |
| **5** | System Arm / standby (admin PIN) |

**Do not use 9090 for declaring codes in a crisis** if you have the app or fob — use Alert Mobile or an armed fob.

## Campus Horns (speakers)

AI speakers across campus: lobby, hallways, fellowship hall. Emergency audio loops until all clear.
