---
title: System limits
description: What Arnold Alert does not do during an emergency.
---

Arnold Alert **announces** the code on campus speakers. It does **not**:

- Call **911** or text parents automatically
- Lock doors (access control is separate)
- Show slides on TVs yet (planned — **Alert Display** via ATEM + Companion)
- Replace incident commander judgment or room-by-room accountability

## Not emergency tools

| Tool | Why |
|------|-----|
| **9090 / 9099** (Alert Line) | Paging and SIP test — not lockdown/evacuate |
| **Alert Page** (9090 → 1) | Convenience PA only |
| **Class bells** | Schedule and first/second bell — separate permission |

**911 first** when life is at risk. Use Arnold Alert to coordinate campus-wide audio after IC decides a code is appropriate.
