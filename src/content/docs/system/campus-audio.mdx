<h2 id="emergency">Emergency codes</h2>

On campus, Red and Blue can **loop**, **repeat every 2 minutes**, or **play once**. These are one full play of each file.

<AudioClip
  id="code-red"
  title="Code Red — Evacuate"

  src="/audio/Code_Red_Full_Master.ogg"
/>

<AudioClip
  id="code-blue"
  title="Code Blue — Lockdown"

  src="/audio/Code_Blue_Master.ogg"
/>

<AudioClip
  id="all-clear"
  title="All clear — Code Green"
  description="Played twice on campus when IC ends the event. Clip is one play."
  src="/audio/Code_Green_au.ogg"
/>

**Stop horns** silences audio but does **not** end the code. Only **All clear** returns the campus to idle.
